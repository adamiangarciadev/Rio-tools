# Product

## Platform
web

## Purpose and users
RIO Tools centralizes internal retail workflows for stores, warehouse, ecommerce, administration and supervisors. Evidence: README.md and existing index.html.

## Constraints
User authorizes a complete redesign and delegates technology and visual choices. Must work on GitHub Pages. Show a local preview before publishing. Preserve existing app routes, integrations, supervision access and current local modifications. No invented business metrics.

## Stack
Static HTML, CSS and JavaScript; existing independent applications and Google Apps Script integrations.

## Brand
RIO Tools. Spanish interface. User requests portfolio-quality professional design with Apple as a quality reference.
