Sucursales incluidas y criterios

Con archivo se usa la columna Cantidad; con API se suman todas las sucursales disponibles. Se conservan los ajustes negativos. Artículo corresponde al código. Orden: artículo ascendente, color alfabético y talle ascendente (orden numérico para talles numéricos y alfanumérico para letras). Con archivo, la fecha se obtiene de su nombre cuando está disponible; con API corresponde al reporte de origen.
