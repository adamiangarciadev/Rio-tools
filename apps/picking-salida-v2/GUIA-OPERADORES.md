# Picking Salida V2 — uso diario

**Entrás directamente. No necesitás correo ni contraseña.** Sistemas habilita cada puesto una sola vez.

1. Elegí tu nombre, origen, destino y cantidad de bultos.
2. Escaneá las prendas. Cada lectura suma una unidad, aunque el código se repita. Esperá la confirmación “Conservado”.
3. Si eliminaste una lectura por error, usá **Deshacer eliminación**.
4. Tocá **Revisar y finalizar**. Revisá cantidad, ruta, bultos y códigos sin equivalencia.
5. Confirmá el envío. Podés iniciar otro picking; el anterior sigue visible en **Historial y pendientes**.
6. Despachá cuando figure **Listo para despachar**.

| Lo que aparece | Qué significa |
|---|---|
| En este equipo | Borrador local; todavía no está respaldado en Google. |
| Pendiente de envío | El picking está cerrado y espera confirmación del servidor. |
| Contenido respaldado | Google recibió las prendas; el servidor puede retomar el guardado. |
| Preparando TXT / Actualizando cuadernillo | El circuito todavía está trabajando. |
| Listo para despachar | TXT y cuadernillo fueron verificados. |
| Requiere atención | Avisá a Sistemas; conservá la operación y su identificación. |

**Si se corta Internet:** seguí conservando el borrador en este equipo. El envío se reanuda cuando vuelve la conexión. Si tenés que cambiar de computadora antes de que Google confirme recepción, descargá el respaldo JSON e importalo en el otro equipo. Ese archivo conserva el ID original.

**Si dice “Lecturas sin guardar”:** detené el escaneo y usá **Recuperar lecturas**. No cierres la pestaña. Esa advertencia indica que el equipo no pudo completar el guardado local.

**Si el TXT no aparece o hay un error:** abrí el detalle del mismo picking. No vuelvas a escanear toda la salida como si fuera otra; eso sería un pedido nuevo. Sistemas puede revisar y recuperar la operación original.

Los archivos y remitos del **piloto** son independientes del circuito actual. No importes un TXT de ensayo como una salida real.
