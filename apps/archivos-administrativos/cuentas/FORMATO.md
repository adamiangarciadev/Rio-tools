# Formato de cuentas para depósito

Las cuentas deben publicarse como fichas A4 con el formato RÍO del archivo
`rio-santander-johanna-suets.pdf`: logo, cabecera, banco, titular, CBU destacado,
CUIL, sucursal, número y tipo de cuenta, y pie institucional.

Usar esa ficha como referencia visual para las nuevas cuentas. No publicar la
foto recibida como comprobante final: transcribir los datos, conservar el tipo
de cuenta indicado por la fuente y verificar el PDF renderizado antes de publicar.

Criterio confirmado por el usuario el 16 de octubre de 2026.
